다섯 날의 작업 총람

커맨드를 못 넣는 사람도 필살기를 쓸 수 있게 만드는 일. 브라우저 실행기 한 장에서 시작해 에뮬레이터 코어와 안드로이드 앱까지, 같은 엔진을 세 갈래로 옮겼다. 2026년 8월 15일부터 20일까지, 판본 43개.

서문무엇을 만들었나

문제는 커맨드다. ↓↘→＋A 같은 입력은 격투게임을 아는 사람에게도 손이 따라야 하는 일이고, 손이 불편하거나 화면 터치로 하는 사람에게는 사실상 벽이다. 그런데 게임 자체는 재미있다. 그래서 커맨드를 몰라도 되게 만들기로 했다.

방법은 단순하다. 버튼 하나(SP)를 누르면 프로그램이 대신 커맨드를 넣는다. 방향은 게임 메모리에서 캐릭터가 바라보는 쪽을 읽어 자동으로 뒤집는다. 왼쪽을 보고 있으면 ↓↙←로 바꿔 넣는 식이다. 사람은 ‘어느 기술을 낼지’만 정하면 된다.

거기서 한 걸음 더 갔다. 혼자 하는 레트로 게임은 조용하다. 그래서 캐릭터가 해설을 붙이게 했다. 하오마루·나코루루·한조·갈포드 넷 중 하나를 고르면, 게임 메모리를 읽어 지금 무슨 일이 일어났는지 알아채고 그 캐릭터의 말투로 한 마디씩 던진다. 정보 전달이 아니라 분위기다.

01세 갈래 — 같은 엔진, 다른 껍데기

핵심은 순수 C로 쓴 엔진 두 개다. ss2sp.c(원버튼)와 ss2comm.c(해설). 브라우저판은 같은 논리를 자바스크립트로 갖고, 코어와 APK는 이 C 파일을 그대로 컴파일한다. 한 곳을 고치면 세 곳이 같이 고쳐진다.

  • 뒤 + A+B = 비오의
  • 강약 — 버튼을 잡고 있으면 강, 짧게 누르면 약
  • 방향 자동 미러링 — 게임 메모리의 facing을 읽어 커맨드를 뒤집는다
  • 카드 게이트 — 카드가 있어야 나가는 기술은 없으면 건너뛰고 이유를 알려 준다
  • 입력 링 리셋(0x1DCD) — 앞서 눌린 방향이 커맨드에 섞여 다른 기술이 나가는 것을 막는다

카드 그림을 롬에서 직접 그리기

마지막 날에는 한 걸음 더 갔다. 카드 아트가 압축돼 있는지를 확인하려고 코어에 롬 읽기 추적을 심고, 팔레트 치환에 불변인 서명으로 2MB를 1바이트씩 훑었다. 결론은 압축이 아니었다. 타일 위치와 팔레트 표를 찾아, 화면 캡처 없이 롬 바이트만으로 카드 그림을 재현했다.

04어떻게 일했나 — 검증

“고쳤다”고 말하려면 증명이 필요했다. 그래서 검증 환경부터 만들었다.

  • 브라우저 회귀 검사 108건 — 실제 롬을 물린 크로미움에서 입력·발동·해설·설정을 자동으로 돌린다. 판을 낼 때마다 전원 통과를 확인했다
  • libretro 프론트엔드(drive.py) — 코어에 롬을 물려 프레임 단위 실행·입력 주입·RAM 감시·스크린샷. 레트로아크 없이 코어를 직접 검증한다
  • VRAM·롬 읽기 추적 — 코어에 디버그 훅을 심어 타일·팔레트·타일맵이 어디서 오는지 프레임 단위로 잡았다 (배포 코어에서는 되돌렸다)
  • 단위 검사 — 카드 게이트·근접표는 롬 없이 C 파일만 컴파일해 확인
추측을 숫자로 바꾸는 것이 원칙이었다. “코어가 브라우저보다 느린가” 같은 물음에는 프레임 수를 세어 답했고(코어 3f/6f 126/144 = 88% vs 브라우저 121/144 = 84%), “카드 그림이 압축인가”에는 롬 전역 검색으로 답했다. 한 번은 내가 낸 오진을 스스로 뒤집기도 했다 — “lore 대사가 죽어 있다”고 보고했지만, 추출기가 한 줄에 같이 선언된 항목을 놓친 것이었다.

06마지막 날에 잡은 버그 넷

모두 사용자가 실제로 플레이하다 보낸 제보다. 원인이 전부 “타이밍”이었다.

제보원인고침
“한 판 끝나면 뜬금없이 온다! 비오의!” 승부가 난 뒤 승리 포즈도 액션ID가 0x180을 넘는다. 그걸 필살기로 읽었다 둘 다 살아 있고 KO 처리 전일 때만 기술로 본다
“SP가 귀신터치마냥 눌린다” 못 내는 입력을 최대 1.5초 예약해 뒀다가 냈다. 그 사이 손은 이미 다음 동작 중 예약 창 0.4초로 축소 + 새 입력이 오면 즉시 폐기
“준비할 때마다 천천히 골라라” 메뉴 잡담 타이머를 화면 전환 때만 리셋했는데, 전투 이탈과 화면 전환이 다른 순간에 일어나 그 사이로 샜다 전투를 벗어날 때 리셋 + 결과 뒤 10초 침묵 적용
“뒤+A+B 하면 SP도 같이 클릭되는 효과” 발동 함수가 불 들어올 버튼을 SP로 못 박아 뒀다 부른 쪽이 정하게 — A+B에만 불이 들어온다
