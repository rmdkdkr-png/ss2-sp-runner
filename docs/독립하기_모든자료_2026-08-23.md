>
> 리다이렉트도 바뀌었다: 옛 문서의 `objects.githubusercontent.com` 이 아니라
> 지금은 `release-assets.githubusercontent.com` 으로 간다.
>
> **그러니 받아 보기 전에는 된다고 가정하지 마라:**
> ```sh
> curl -sL -o /tmp/NgpEmu.apk https://github.com/rmdkdkr-png/emu-ex-plus-alpha/releases/download/Pre-release/NgpEmu.apk
> file /tmp/NgpEmu.apk    # "Android package (APK)" 가 나와야 진짜다
> ```

# 2. 방에서 구글 여는 법 — 이게 제일 중요하다

`dl.google.com` 이 403 이면 안드로이드 SDK·NDK 를 못 받아 **로컬 빌드가 아예 성립하지 않는다.**
이건 방 안에서 못 고친다. **환경 설정을 바꿔야 한다.**

## 누르는 순서

1. [claude.ai/code](https://claude.ai/code) 에서 **메시지 입력창 바로 윗줄의 구름 아이콘**을 누른다
   (지금 환경 이름이 적혀 있는 버튼). 설정 페이지나 직접 URL 은 없다
2. 그 방이 쓰는 환경 위에 마우스를 올리면 **오른쪽에 톱니바퀴**가 뜬다. 누른다
3. **「네트워크 액세스」를 「신뢰됨」에서 「사용자 지정」으로 바꾼다**
   ← 이걸 해야 「허용된 도메인」 칸이 **나타난다**
4. 새로 생긴 **「허용된 도메인」** 칸에 한 줄에 하나씩:

```
dl.google.com
maven.google.com
repo1.maven.org
plugins.gradle.org
services.gradle.org
*.frame.claudeusercontent.com
```

5. **「일반적인 패키지 매니저의 기본 목록도 포함」 체크** — 안 하면 깃허브·npm·pypi 가 다 막힌다
6. 저장하고 **그 방을 새로 연다.** 돌고 있는 세션은 시작할 때 값을 한 번만 읽는다

## 자주 하는 실수

**도메인을 「환경 변수」 칸에 넣는 것.** 거기는 `KEY=value` 만 받아서
`Couldn't parse "dl.google.com". Use KEY=value format.` 이 뜬다.
**「허용된 도메인」은 별개 칸이고, 「사용자 지정」을 골라야 나타난다.**

## 설정 스크립트 (선택)

넣어 두면 세션 시작 때 SDK 가 받아져 캐시에 남는다. 실측으로 준비(§1~§6)가
3분 → 1분 40초로 줄었다. 세션 안에서 `sdkmanager` 를 다시 돌려도 **18초에 끝난다** —
받아 둔 것이 있어서다. NDK 는 스크립트에 안 넣었고, 방 안에서 받아 46초 걸렸다.

```bash
#!/bin/bash
export ANDROID_HOME="$HOME/android-sdk"
mkdir -p "$ANDROID_HOME/cmdline-tools" && cd /tmp
curl -sSL -o cmdline.zip https://dl.google.com/android/repository/commandlinetools-linux-13114758_latest.zip || exit 0
unzip -q cmdline.zip -d /tmp/cmdt && mv /tmp/cmdt/cmdline-tools "$ANDROID_HOME/cmdline-tools/latest"
yes | "$ANDROID_HOME/cmdline-tools/latest/bin/sdkmanager" --licenses >/dev/null 2>&1
"$ANDROID_HOME/cmdline-tools/latest/bin/sdkmanager" \
  "platform-tools" "platforms;android-36" "build-tools;36.0.0" >/dev/null 2>&1
echo "SDK ready at $ANDROID_HOME"
```

> **반드시 `android-36` 이다.** 34 로는 안 된다 — NGP.emu 가 compileSdk 36 이다.
> **NDK 는 넣지 마라.** 713MB 라 세션 시작이 너무 느려진다. 방 안에서 받으면 된다.

## 방 상태 확인 세 줄

```sh
curl -s -o /dev/null -w '%{http_code}\n' https://dl.google.com/android/repository/repository2-3.xml   # 200 이어야 빌드 가능

# 4. 구운 것이 맞는지 — 검증 기준표

**해시가 다른 것이 곧 소스가 다른 것은 아니다.** 아래 값으로 판정해라.

`.so` 가 갈리는 원인은 **경로가 아니라 빌드 환경**이다. 실측으로 확인했다:
서로 다른 경로의 방 빌드 둘이 `.so` 네 개의 크기가 모두 같았고,
서로 다른 저장소의 CI 빌드 둘은 `.so` 가 CRC 까지 같았다. 방 빌드와 CI 빌드 사이에서만
8바이트 차이가 났다(CI 는 temurin JDK · lukka/get-cmake 를 쓴다).
그러니 **같은 길로 구운 것끼리는 `.so` md5 도 맞아야 한다.**

## 무조건 같아야 하는 것

```
package    com.rmdkdkr.ngpemu.ss2   versionCode 16010585   versionName 1.5.85
ABI        arm64-v8a  armeabi-v7a  x86  x86_64
assets/gpOverlay.png  md5 = 24bed154fbd45b774a8410e90aaf8483
ss2comm_lines.h       md5 = 25eee52f4ee9ea3a16a4a2447082d594
ss2comm_font11.h      md5 = 33d75f153058a6a61f4e508f75677695
```

## `lib/arm64-v8a/libmain.so` 안 문자열 개수

| 문자열 | 개수 |
|---|---|
| `SS2 Commentator` | 1 |
| `SS2 Commentary Display` | 1 |
| `Band above screen` | 1 |
| `겐주로` | 24 |
| `하오마루` | 24 |
| `리쿠도렛카` | 1 |
| `마를 봉하는 사람` | 1 |
| `유파는 달라도 저분처럼` | 1 |
| `한조는 잘 있으려나` | 1 |
| **`딸들`** | **0** — 남아 있으면 옛 소스다 |
| **`붓 한 자루로 싸우는 화가`** | **0** — 남아 있으면 옛 소스다 |

세는 법:

```sh
LC_ALL=C grep -a -o -F "겐주로" lib/arm64-v8a/libmain.so | wc -l
```

> **`strings` 로 세지 마라.** ASCII 만 뽑아서 한글이 0 으로 나온다. 이걸로 한 번 오진했다.

> **`겐주로`·`하오마루` 가 23 이면 옛 대사표다.** `EVMAXV` 가 10 으로 굳어 있어
> `charselChat` 에서 여덟 줄이 잘려 나갔던 판이다. 되살린 판에서는 24 다 —
> 늘어난 두 줄은 "…겐주로. 삿된 검이다" 와 "하오마루 씨는… 또 술 냄새가 나는 것 같아요" 다.

## 달라도 되는 것

`.so` 의 md5·크기, APK 전체 md5(서명 키가 다르다), 빌드 시각.

참고로 방에서 구운 `.so` 크기(옛 대사표 기준): arm64 2,621,888 / armv7 1,833,052 / x86 2,671,984 / x86_64 2,970,480.
CI 빌드는 arm64 가 2,621,880 으로 8바이트 작다.
새 대사표를 쓰면 표가 커져서 arm64 는 2,661,408 이 된다.

## 글꼴 BDF 받는 곳

폰트 파일은 저장소에 없다(임베드는 되지만 재배포는 안 한다). 둘 중 아무 데서나:

# 또는

# 7. 절대 어기면 안 되는 것

1. **롬을 어떤 저장소·페이지·아티팩트에도 넣지 않는다.** 세이브스테이트도 마찬가지
2. **SNK 그림을 배포물에 넣지 않는다.** 해설자 얼굴은 실행 중에 사용자 롬에서 뽑는다
3. **글꼴 파일(BDF)도 넣지 않는다.** 받는 법만 적는다
4. 꾸러미를 만들 때마다:
   `find . \( -name '*.ngc' -o -name '*.ngp' -o -name 'st_*.bin' \)`
5. **확실하지 않은 설정을 대사에 쓰지 않는다.** 조사 문서의 확실도 표시를 지켜라
