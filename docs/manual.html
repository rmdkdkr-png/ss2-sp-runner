01어떻게 쓰나

↓↘→ 대신 SP 버튼 하나. 방향을 같이 눌러서 어느 기술을 낼지 고른다.

SP중립 필살기 — 버튼 직결의 SP1 과 같은 기술
→ + SP앞
← + SP뒤
↓ + SP아래
↘ / ↙ + SP대각
점프 중 SP공중기
SP 를 지그시강 (9프레임 넘기면)

이 문서의 방향과 커맨드는 전부 1P 기준이다 — 왼쪽에 서서 오른쪽을 볼 때. 실제로는 좌우를 신경 쓸 필요가 없다. 캐릭터가 보는 쪽을 램(0x0E54)에서 읽어 커맨드를 뒤집는다.

02기본 배치

03치트는 아니다

하는 일은 입력을 대신 넣는 것뿐
  • 없는 기술을 만들지 않는다
  • 게임 데이터를 고치지 않는다
  • 맞는 중에는 안 나간다
  • 공중 판정 그대로
  • 헛손질한 잡기는 그대로 헛손질

커맨드 판정 루틴(0x202E8B)이 입력 기록을 뒤에서부터 훑으면서 안 맞는 입력은 건너뛴다. 직전 입력 찌꺼기가 남아 있으면 짧은 커맨드가 긴 커맨드를 잡아먹는다. 손이 느린 게 아니라 구조가 그렇다. 0x1DCD에 1을 쓰면 게임이 원래 갖고 있는 리셋 루틴이 돌아서 입력 기록을 정리한다. 프레임을 더 먹지도 않는다.

롬은 어디에도 들어 있지 않다. 본인이 소유한 파일을 쓸 것.
