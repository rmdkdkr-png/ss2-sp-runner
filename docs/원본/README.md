# 원본 인계 문서

여기 있는 것은 **다른 방에서 손으로 건네받은 문서를 그대로 넣은 것**이다.
고치지 않았다. 내용이 지금과 어긋나는 곳이 있어도 그대로 뒀다 —
그 방들이 무엇을 알고 무엇을 몰랐는지가 기록으로 남아야 하기 때문이다.

지금 기준으로 어긋난 곳:

- `SS2_코드방이식_먼저읽기` 는 「깃허브에 올라가 있는 것은 아직 v0.6」이라고 하는데,
  **v0.7a 가 세 저장소에 다 올라가 있다.**
- 같은 문서가 「이 방에서는 안드로이드 SDK 를 받을 수 없다」고 하는데,
  그건 **방마다 다르다.** 환경의 네트워크 접근을 열면 받아진다 —
  여는 법은 `../독립하기_모든자료_2026-08-23.md` §2 에 있다.
- 릴리스 문서의 다운로드 리다이렉트가 `objects.githubusercontent.com` 으로 적혀 있는데,
  지금은 `release-assets.githubusercontent.com` 으로 간다.

**지금 무엇을 해야 하는지는 이 폴더 말고 위층을 봐라:**

- `../독립하기_모든자료_2026-08-23.md` — 모든 자료의 자리, 환경 여는 법, 검증 기준
- `../인계_2026-08-23_방나누기와_다음과정.md` — 방 나누는 법, 다음 과정
- `../../../emu-ex-plus-alpha/master/BUILD.md` — 빌드 레시피

그래도 이 폴더가 값진 이유는, **여기에만 있는 것이 있기 때문이다:**

- 글꼴 포장 규칙(ascent·비트 순서·행 수) — 역해석해서 비트 단위로 맞춘 것
- 웹뷰 함정(파일 선택기, wasm XHR, MIME, 가로세로)
- 시험 규칙(낱말 말고 이벤트로 맞춰라, 큐를 비우려면 900~1200프레임)
- 짝꿍 시계가 둘이라는 것(`duoAt`, `duoBigAt`)과 초기값을 `-1e7` 로 둬야 하는 이유
- 프로젝트 문서 115편의 색인 — 서버에 있는 문서를 찾아가는 지도
- 말투 — 사용자가 어떤 답을 원하는지
