## 0. 절대 어기면 안 되는 것 (세 줄)

1. **롬을 어떤 저장소·페이지·아티팩트에도 넣지 않는다. 세이브스테이트도 마찬가지.**
2. **SNK 그림을 배포물에 넣지 않는다.** 필요하면 사용자 롬에서 **실행 중에** 뽑는다.
3. 올릴 때 `.ngc` · `.ngp` · `st_*.bin` 은 절대 같이 올리지 않는다.

꾸러미를 만들 때마다 이걸 돌리고 넣는다:
```
find . \( -name '*.ngc' -o -name '*.ngp' -o -name 'st_*.bin' \)
```

## 1. 무엇을 만들고 있나

네오지오 포켓 컬러 『사무라이 스피리츠! 2』 를 **손이 불편해도 즐길 수 있게** 만드는 접근성 도구.
기능은 **둘이고, 서로 별개**다. 하나만 켜도 되고, 따로 떼서 다른 게임에 붙일 수도 있다.

| | 기능 | 하는 일 | 게임마다 드는 품 |
|---|---|---|---|
| 1 | **SP 버튼** | 버튼 하나로 필살기가 나간다 (커맨드 입력 대행) | **크다** — 게임마다 메모리 구조를 뜯어야 한다 |
| 2 | **해설** | 캐릭터가 경기를 말로 중계한다 | **작다** — 대사표만 갈아 끼우면 된다 |

이 둘이 별개라는 건 사용자가 직접 짚은 것이다. 다른 NGP 격투 게임으로 넓힐 때
**해설만 먼저 붙이는 게 싸다** — 근거: `claude/SS2_여러게임_한코어_가능성_2026-08-22.md`

## 세 갈래로 나간다

| 갈래 | 무엇 | 저장소 |
|---|---|---|
| 브라우저판 | `index.html` 한 장 (EmulatorJS + PWA) | `rmdkdkr-png/ss2-sp-runner` |
| 코어판 | libretro 코어 (Beetle NeoPop 포크) | `rmdkdkr-png/ss2-sp-core` |
| 앱판 | 안드로이드 APK (NGP.emu 포크) | `rmdkdkr-png/emu-ex-plus-alpha` |

**브라우저판이 프로토타입이다.** 여기서 먼저 만들고 눈으로 확인한 뒤 C 로 옮긴다.
`ss2sp.c` · `ss2comm.c` 는 코어판과 앱판이 **같은 파일을 공유**한다 — 한쪽만 고치면 어긋난다.
(딱 한 줄만 다르다: 앱판은 `#include <ss2comm/ss2comm.h>`, 코어판은 `#include "ss2comm.h"`.)

## 4. 이번에 고친 것 — v0.7 → v0.7a

**기술 이름 글자가 화면에서 빠지던 문제.**
「리쿠도렛카」가 「리쿠도　카」로, 「화염격」이 「화　격」으로 나왔다(사용자 화면 사진으로 확인).

원인: 글꼴을 뽑는 `tools/gen_font.js` 가 **대사표만 훑고 기술 이름 파일은 안 훑았다.**
기술명은 대사에 `%s` 로 끼워 넣는 것이라 대사표 안에 그 글자가 없다.

고침: `SRC` 목록에 `ss2sp_moves.h` · `ss2sp.c` · `ss2sp.h` 를 넣었다.

확인:

- **741자 → 825자** (font11), 741 → 826 (font8)
- 원래 있던 741자는 **비트 하나 안 달라졌다** (한 자씩 대조)
- 「렛」(U+B81B) 이 이제 두 글꼴 모두에 들어 있다
- 세 갈래 글꼴 파일 md5 일치
- 코어 3종(linux x86_64 / linux aarch64 / windows dll) 다시 빌드 → 바이너리 안에서 U+B81B 확인, `dlopen` + `retro_api_version` 확인

`∼`(U+223C) 한 자만 font11 에 없다. Galmuri11-Condensed BDF 에 그 글자가 없어서인데,
실제 대사에 안 쓰이는 구두점 씨앗이라 문제 없다.

도구 소스 전문은 프로젝트 문서에 박제해 뒀다 → `claude/SS2_도구_글꼴생성기_원본_2026-08-23.md`

- 아수라의 수라/나찰, 시키의 수라/나찰은 **서로 다른 인물**이다

- 쿠로코: 수라는 고정 랜덤 캐릭터, 나찰은 마지막에 이긴 상대로 변한다.

## 6. 코드방이 알아야 할 함정 (같은 실수 두 번 하지 말 것)

### 망 — 이 컨테이너에서 되는 것과 안 되는 것
- **된다**: `github.com/…/releases/download/…` (302→`objects.githubusercontent.com`), `raw.githubusercontent.com`
- **안 된다**: `dl.google.com`, `maven.google.com`, `ghcr.io`, `registry-1.docker.io`, `codeload.github.com`, `api.github.com`

안드로이드 SDK 를 받을 수 없다. 그래서 APK 는 **apktool + smali** 로 만든다:
apktool.jar(깃허브 릴리스) 안에 `prebuilt/linux/aapt2_64` 가 들어 있다.
d8/dx 가 없어 Activity 를 smali 로 직접 쓴다.
서명은 `uber-apk-signer` — **v1+v2+v3 를 한 번에.**
**v1 만 서명하면 안드로이드 11+ 에서 설치가 안 된다.**
→ `claude/SS2_v07_복구와_APK를_방안에서_2026-08-23.md`

정식 APK 는 깃허브 Actions 로 만든다. 왕복이 35분 → 10분으로 줄었다
(파일 점검 20초 + 밑작업 캐시 + 에뮬레이터 하나만 빌드).
→ `claude/SS2_APK왕복_줄이기_방도_2026-08-22.md`

### 빌드
- `build.sh` 는 대상을 **인자로** 받는다. `TARGET=` 가 아니라 `./build.sh linux-aarch64`.
- 메이크파일이 플랫폼별로 `CXX` 를 덮어쓴다 → `CC=… CXX=… make -e` 로 해야 먹는다.
  (이걸 몰라서 크로스 빌드가 말없이 호스트 g++ 로 돌았다.)
- `WORK=…` 로 빌드 트리 위치를 지정할 수 있다. 없으면 `build/` 에 clone 한다.
- `.patch` 를 손으로 고치지 마라. 훅 머리(`@@ -a,b +c,d @@`)가 어긋난다. 다시 세어 쓰는 스크립트를 써라.

### 웹뷰 (APK 안에 브라우저판을 넣을 때)
- `?data=./data/` 를 안 붙이면 EmulatorJS 가 제 CDN 을 때린다.
- wasm XHR 때문에 `setAllowFileAccessFromFileURLs` · `setAllowUniversalAccessFromFileURLs` 필요.
- `onShowFileChooser` 를 구현 안 하면 `<input type=file>` 이 **아무 반응 없이** 죽는다.
  취소했을 때 **null 을 돌려주지 않으면** 입력칸이 영영 잠긴다.
- MIME 은 `*/*`. 확장자는 MIME 이 아니다.
- 가로세로: `screenOrientation="fullSensor"`. 전체화면은 `onWindowFocusChanged` 에서 다시 걸어야 한다.

### 시험
- 해설 회귀시험은 **낱말로 맞추지 마라.** 대사가 늘 때마다 깨진다.
  **어떤 이벤트가 떴는지**로 맞춘다 (`commEvLog` / `window.__ss2.commEvs`, C 쪽은 `lineIsEv()`).
- C 큐는 한 프레임에 한 줄씩 나오고 줄마다 100~150프레임 잡고 있다.
  시험은 900~1200프레임 돌려 비워야 한다.
- 검증 도구의 `pick` 을 "첫 원소 반환" 스텁으로 두면, 읽는 쪽이 없는 분기를 상상해 낸다. **난수로 둬라.**
- `EVCD[EV_N]` 을 다 안 채우면 새 이벤트가 조용히 기본 쿨다운을 먹는다. 이벤트를 늘리면 같이 늘려라.
- 짝꿍 시계는 **둘**이다(`duoAt`, `duoBigAt`). 하나로 두면 큰 장면이 잔 대사에 막힌다.
  초기값을 `0` 으로 두면 페이지가 뜬 뒤 6초 동안 아무 대꾸도 안 한다 — `-1e7` 로 둔다.

### 글꼴 포장 규칙 (역해석해서 비트 단위로 맞춘 것)
```
ss2comm_font11.h = Galmuri11-Condensed · ascent 11 · x=0 이 비트11 · 13줄
ss2comm_font.h   = Galmuri7            · ascent 7  · x=0 이 비트7  · 8줄
y = ascent - BBX.yoff - BBX.height + r ,  x = BBX.xoff + c
```
Galmuri 는 SIL OFL 1.1. 임베드·재배포가 되지만 **폰트 파일 자체를 그대로 재배포하지는 않는다.**
BDF 원본은 `/tmp/package/dist/*.bdf` 에 있었다 (galmuri 배포판을 풀어 둔 것).
