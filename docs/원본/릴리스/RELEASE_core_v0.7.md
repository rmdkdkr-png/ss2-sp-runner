- 코어 옵션 **SS2 Commentary Speaker** 에서 고릅니다
- **게임 중 L2 를 누르면 다음 해설자에게 넘어갑니다** (설정을 안 열어도 됩니다)

대사는 3,700줄, 글리프는 825자로 늘었습니다.
대사표·글꼴 모두 브라우저판에서 **기계로 뽑은 것**이라 세 갈래가 같은 말을 합니다.

첨부한 `.so` 둘과 `.dll` 하나는 여기서 직접 빌드한 것입니다
(linux x86_64 / linux aarch64 / windows x86_64).

## 해설이 「판 전체」를 읽습니다

방금 일어난 일이 아니라 **쌓인 흐름**에 반응합니다 — 같은 기술에 세 번 걸릴 때,
서로 주고받는 난타전일 때, 한 대도 안 내주고 밀어붙일 때, 반대로 계속 쫓길 때,
상대가 필살기만 노릴 때. 매치가 끝나면 **판의 모양**을 읽습니다:
"첫 판을 내주고 내리 두 판. 뒤집었군" 처럼요.

## v0.7a — 기술 이름 글자가 빠지던 것 수정

「리쿠도렛카」가 「리쿠도　카」로, 「화염격」이 「화　격」으로 나오던 문제입니다.

`ss2sp_moves.h` 까지 훑도록 고쳐 **741자 → 825자**가 됐습니다.
이미 있던 741자는 비트 하나 안 달라졌습니다(대조 확인).
