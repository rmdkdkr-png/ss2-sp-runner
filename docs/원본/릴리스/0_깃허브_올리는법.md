## 1. `ss2-sp-runner` — 브라우저 실행기 (Pages)

폴더 **`1_runner/`** 의 내용물을 저장소 **최상단**에 올립니다.

1. https://github.com/rmdkdkr-png/ss2-sp-runner 로 갑니다
2. **Add file → Upload files**
3. `1_runner/` **안의 것들을** 통째로 끌어다 놓습니다 (폴더 `1_runner` 자체가 아니라, 그 안의 파일·폴더들)
4. 아래 커밋 메시지를 붙여넣고 **Commit changes**

```
v0.6 — 확정판: 촬영 모드 · 더미 상대 · 가로 모드 · 시작 화면 정리

- 촬영 모드: 기술이 나갈 때 [누른 것 ▶ 실제 커맨드] 자막 (녹화·시연용, 기본 끔)
  글자 점등이 실제 입력 시점 · 자막도 배치 편집에서 끌어 옮김
- 더미 상대: 반격하지 않는 연습 상대 (기본 끔) · 켜면 시간·체력 최대 고정
  내 움직임은 그대로, 상대만 멈춤
- 가로 모드: 조작판이 고정 300px을 먹어 게임이 0~47px로 짜부라지던 것 수정
  가로에선 조작판을 게임 위에 얹고, 버튼을 조밀한 마름모로 모음
- 상단 줄 잘림 수정 — 좁은 화면에선 캐릭터 유파를 떼고 이름만 (340px에서도 8개 다 들어옴)
- 카드 선택을 건너뛰고 시작해도 양옆 스테이지 아트가 붙음
- 시작 화면 시연 움짤 제거 — html 한 장 1.05MB → 464KB. 시연은 README 로
- README 그림 교체 (움짤 9개, 저장소 12.7MB → 5.7MB)
- 회귀 128건 통과
```

### ⚠️ 지워야 할 옛 파일 — 이것만은 손으로

**깃허브 웹 업로드는 파일을 덮어쓰기만 하고 지우지는 않습니다.**
그림을 갈아 끼웠기 때문에, 아래 6개가 남아 있으면 저장소가 10MB 넘게 헛돕니다.

저장소에서 파일을 열고 **휴지통 아이콘 → Commit changes** 로 지우시면 됩니다.

```
docs/clips/play_1.webp
docs/clips/play_2.webp
docs/clips/play_3.webp
docs/shots/play_1_still.webp
docs/shots/play_2_still.webp
docs/shots/play_3_still.webp
docs/shots/demo.gif
```

지우면 저장소가 **12.7MB → 5.7MB** 가 됩니다. (안 지워도 사이트는 정상 동작합니다 — 용량만 낭비)

### 이번에 바뀌는 그림

```
docs/clips/hero.webp          대문 움짤 — SP 한 번에 삼련살·앵화참·광양인 (자막 포함)
docs/clips/super.webp         뒤+A+B = 비오의
docs/clips/ko.webp            KO
docs/clips/line_*.webp (4)    해설 — 나코루루(나찰)·한조·하오마루 술·하오마루 승리
docs/clips/sideart.webp       양옆 카드 아트
docs/clips/combo.webp         세로 화면 실기 플레이
docs/shots/*_still.webp       위 정지컷들
docs/shots/10_landscape.webp  가로 기본 배치
docs/shots/11_portrait.webp   세로 기본 배치
docs/shots/12_settings.webp   설정
```

### Pages 확인

**Settings → Pages → Source: Deploy from a branch → `main` / `(root)`**

이미 켜져 있으면 그대로 두시면 됩니다. 2~3분 뒤 반영됩니다.

- 실행기 → https://rmdkdkr-png.github.io/ss2-sp-runner/
- 총람 → https://rmdkdkr-png.github.io/ss2-sp-runner/docs/총람.html

### 올린 뒤 30초 점검

1. 위 주소를 **휴대폰에서** 엽니다
2. 상단 줄에 **8개가 다 보이는지** (세이브·로드·슬롯·아트·설치·캐릭터명·⚙·⛶)
3. 상단 **[설치]** 를 눌러 홈 화면에 들어가는지
4. 롬을 고르고 판이 서면 — 위쪽에 해설 띠, 세로면 양옆에 아트
5. **폰을 가로로 눕혀** 게임이 크게 서는지, 버튼 넷이 오른쪽에 조밀하게 모이는지
6. 설정에 **[촬영 모드]** 와 **[더미 상대]** 가 있는지. 촬영 모드를 켜고 SP를 눌러
   화면에 「기술명 / SP ▶ ↓ ↘ → ＋ A」 가 뜨는지

> ⚠️ **다음 판을 올릴 때는 `sw.js` 안의 `VER` 문자열을 꼭 바꾸세요.**
> 지금은 `ss2sp-v0.6` 입니다. 안 바꾸면 옛 캐시가 남아 새 판이 안 보입니다.

## 2. `ss2-sp-core` — libretro 코어

**이번에 v0.6 으로 재빌드했습니다.** 코어 파일 세 개가 바뀌었으니 다시 올려 주세요.

폴더 **`2_core/`** 의 내용물을 저장소 최상단에 올립니다.

```
v0.6 — 판올림 재빌드 (엔진은 브라우저·APK 와 같은 판)

- 레트로아크 코어 정보 표기: v1.29.0.0 · SS2 v0.6
- linux x86_64 / linux aarch64 / windows dll 재빌드 — 셋 다 여기서 실제로 만들었습니다
- 호스트 코어로 롬을 물려 전투 상태에서 SP 발동까지 확인 (액션ID 0x1C0)
- build.sh 수정: 지난 빌드의 패치가 인덱스에 남아 판올림 때 충돌하던 것
  (checkout -- . → reset --hard)
```

`cores/` 안의 `.so` · `.dll` 세 개는 **여기서 실제로 빌드해서 dlopen 까지 확인한 것**입니다.
안드로이드용은 이 환경에서 못 만듭니다 — 필요하면 저장소의 Actions 로 돌리세요.

> 촬영 모드·더미 상대는 **브라우저 실행기 전용**입니다. 코어에는 아직 없습니다.

## 문제가 생기면

| 증상 | 이유 | 조치 |
|---|---|---|
| 새 판이 안 보인다 | 서비스워커가 옛 판을 캐시 | `sw.js` 의 `VER`(`ss2sp-v0.6`)이 올라갔는지 확인 · 또는 브라우저 설정에서 사이트 데이터 지우기 |
| [설치] 버튼을 눌렀는데 "파일로 직접 연 상태" | 내려받은 html 을 파일 관리자로 열었음 | **Pages 주소(https)** 로 들어가서 누르기. 내려받은 파일은 오프라인 전용입니다 |
| 대문 움짤이 안 움직인다 | 이미지 캐시 | 새로고침. 애니메이션 webp라 깃허브에서 그대로 재생됩니다 |
| 가로로 눕혔는데 게임이 작다 | 옛 판이 캐시됨 | 위 서비스워커 항목대로 |
| 오프라인이 안 된다 | `sw.js` 가 최상단이 아님 | `sw.js` 는 반드시 `index.html` 과 같은 폴더에 |
| 총람 페이지가 안 열린다 | 경로 오타 | `docs/총람.html` — 한글 파일명이라 주소창에서 인코딩될 수 있는데 정상입니다 |
| APK 빌드가 죽는다 | 파일이 빠졌거나 옛 판 | 맨 앞 **SS2 파일 점검** 잡의 빨간 줄을 보세요 — 어느 파일인지 이름으로 말해 줍니다 |
